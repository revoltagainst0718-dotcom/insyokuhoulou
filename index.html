キーの作り方

  1. Google Cloud Consoleで新しいプロジェクトを作成
  2. 課金（請求先アカウント）を設定する
  3. 「APIとサービス」→「ライブラリ」から Places API (New) を有効化
  4. 「認証情報」から新しいAPIキーを作成し、APIの制限を Places API (New) のみに絞る
  5. 予算アラートと1分あたりの上限（クォータ）を必ず設定しておく
